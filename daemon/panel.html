Backlight brightness

PWM on the backlight pin. Reset to 100 % when the board loses power; hwmond re-sends the chosen value when the display reconnects.

Screen content

The normal page: CPU / GPU temperature, load and power, RAM, disks, CPU and GPU fan speeds. hwmond reads the sensors every second and sends one SRC=OS frame.

Start a line with #ok: #warn: #hot: #accent: #dim: to colour just that line. An empty line leaves a gap. ASCII only: the display's 6×8 font has nothing else.
